# Security Policy

## Reporting a Vulnerability

We take the security of Metricore.in seriously. If you discover a security vulnerability, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to:
`security@metricore.in` (or contact the repository maintainer directly via GitHub Security Advisories).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (proof-of-concept scripts, screenshots, or curl requests).
- Any recommended remediation steps.

We will acknowledge receipt within 48 hours and work on a prompt resolution.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
